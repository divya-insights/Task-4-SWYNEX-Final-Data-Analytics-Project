# Task 4 – SWYNEX Final Data Analytics Project

## 1. Project Overview

This project presents an end-to-end Data Analytics solution using a retail store sales dataset. It combines data cleaning, exploratory data analysis (EDA), and an interactive Power BI dashboard to identify meaningful business insights and support data-driven decision-making.

## 2. Problem Statement

The objective of this project is to analyze retail sales data to understand sales performance, customer purchasing patterns, product category performance, payment methods, and sales channel trends. The analysis aims to identify useful business insights and provide recommendations for improving retail performance.

## 3. Dataset Description

The project uses a retail store sales dataset containing transaction-level information.

Key fields include:

- Transaction Date

- Customer ID

- Category and Item

- Price Per Unit

- Quantity

- Total Spent

- Payment Method

- Location

- Discount Applied

## 4. Data Cleaning and Preparation

Data cleaning was performed as part of Task 1.

Key activities included:

- Identifying missing values

- Checking duplicate records

- Reviewing data types and inconsistencies

- Standardizing payment method values

- Preparing cleaned fields for analysis

- Handling incomplete price and transaction values where possible

## 5. Exploratory Data Analysis (EDA)

Python was used for exploratory data analysis as part of Task 2.

Key activities included:

- Descriptive statistical analysis

- Sales distribution analysis

- Category-wise sales analysis

- Payment method comparison

- Online versus in-store sales comparison

- Visualizations to identify patterns and trends

## 6. Interactive Power BI Dashboard

An interactive dashboard was developed in Power BI as part of Task 3.

The dashboard presents key performance indicators (KPIs), sales visualizations, and business insights to make retail sales performance easier to understand.

## 7. Key Business Insights

The analysis highlighted the following findings:

- Butchers was the highest-performing category by total sales in the analyzed dataset.

- Cash recorded the highest total sales among the three payment methods.

- Online sales were higher than in-store sales.

- The dataset's sales distribution and transaction values can help identify areas for further investigation.
